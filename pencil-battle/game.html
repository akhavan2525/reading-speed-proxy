مشت و لگد

مشت×۳ ← جب، کراس، هوک · لگد×۴ ← جلو، چرخشی، قلاب، پاشنه‌ی چرخشی · جلو+لگد ← بغل · عقب+لگد ← چرخشی از پشت · پایین+لگد ← جارو · پرش+لگد ← گردباد

مشت ← ضربه‌ی افقی · مشت مشت ← رگبار · جلو+مشت ← چرخش + لگد هلالی · عقب+مشت ← چرخش هشتی (ضربه‌ها رو دفع می‌کنه) · پایین+مشت ← پرش و کوبش · شمشیر: مشت مشت ← ضربه‌ی نیزه‌ای + لگد پرتاب‌کننده · خنجر: مشت مشت ← پرتاب دو خنجر و پس‌گرفتن

ویژه و فینیشر

هر خونه‌ی نوار ویژه: ویژه / جلو / عقب / پایین / هوا + ویژه ← حرکات سینمایی. وقتی خون حریف (یا غول) کم شد، فینیشر رو بزن.
داستانی: ده مرحله، از سوپرمارکت تا پشت‌بام شبانه. آدمک‌ها رو بزن تا به رئیس هر مرحله برسی. جعبه‌ها رو بشکن: خون و سلاح دارن! با سکه‌هات از فروشگاه قهرمانت رو قوی‌تر کن.
